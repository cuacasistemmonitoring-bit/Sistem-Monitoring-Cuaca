# Stasiun Klimatologi Yogyakarta - Automatic Weather Station Dashboard

Dashboard monitoring cuaca realtime berbasis Web yang dirancang menyerupai antarmuka stasiun cuaca resmi BMKG (Automatic Weather Station). Dilengkapi dengan widget termometer, kompas angin, grafik tren 24 jam, hingga panel navigasi menu bawah.

## Fitur Utama
- **Layout Grid Lengkap:** Menampilkan parameter lengkap seperti Temperature, Heat Index, Wind Speed & Direction, Barometer, Solar/Light, dan Rainfall.
- **Visualisasi Kompas & Gauge:** Indikator arah mata angin dan kecepatan angin berbasis grafik batang serta kompas digital interaktif.
- **Grafik Tren Waktu Nyata:** Dilengkapi simulasi grafik garis (*sparkline charts*) untuk tren suhu, tekanan udara, dan kecepatan angin dalam 24 jam terakhir.
- **Menu Navigasi Bawah:** Menu bar khas perangkat stasiun cuaca untuk mempermudah akses menu analisis.

## Cara Penggunaan
1. Unduh atau ekstrak file `index.html`.
2. Buka file `index.html` menggunakan browser web apa pun (Google Chrome, Firefox, Edge, dll.).
3. Dashboard siap digunakan untuk keperluan tampilan monitoring atau integrasi sistem IoT/sensor cuaca Anda.
