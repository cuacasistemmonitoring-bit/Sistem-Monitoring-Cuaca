# Weather Monitoring Station - Politeknik Negeri Lampung

Dashboard monitoring cuaca realtime berbasis Web dengan desain modern yang bersih, menggunakan tema warna yang lembut (*soft clean theme*) serta konsistensi warna indikator pada setiap parameter sensor.

## Fitur Utama
- **Desain Soft & Clean:** Menggantikan tema gelap pekat dengan latar belakang terang yang elegan, nyaman dipandang, serta kontras warna teks yang optimal.
- **Konsistensi Warna Simbol:** Setiap parameter (Suhu, Kelembapan, Kecepatan Angin, Intensitas Cahaya, dan Curah Hujan) memiliki identitas warna ikon dan aksen yang selaras.
- **Indikator Realtime:** Dilengkapi dengan animasi status koneksi sistem serta widget visual interaktif (bar vertikal, *circular gauge*, dan kompas arah angin).
- **Responsif:** Tata letak fleksibel yang menyesuaikan tampilan di perangkat desktop maupun *mobile*.

## Struktur File
- `index.html`: File utama antarmuka dashboard monitoring cuaca.
- `README.md`: Dokumentasi penjelasan dan petunjuk penggunaan.

## Cara Penggunaan
1. Unduh atau ekstrak file `index.html`.
2. Buka file `index.html` menggunakan browser modern apa pun (Google Chrome, Mozilla Firefox, Microsoft Edge, dll.).
3. Dashboard siap digunakan dan dapat dihubungkan langsung ke mikrokontroler (seperti ESP32) atau database (seperti Firebase/MySQL) menggunakan JavaScript Fetch API atau WebSocket.
